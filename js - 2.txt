1.

Até onde eu entendo, código síncrono é o comportamento padrão do código em javascript, em que cada linha de código do sistema é executada de forma ininterrupta, mesmo que uma request não retorne imediatamente, então por exemplo:
let frase; setTimeout(() => { frase = 'ola'; console.log('frase é ola') }, 2000); console.log('isso aparece antes'); console.log(frase);"
Nesse caso, console.log(frase) imprime undefined, pois após a chamada de setTimeout o código continua sendo executado. 
O mesmo aconteceria se uma request para uma API fosse realizada: O runtime do js não espera a request retornar uma resposta antes de prosseguir executando o código.
Já no comportamento assíncrono, após a chamada de uma API, o código espera a requisição retornar algo antes de prosseguir.
Uma requisição HTTP é assíncrona pois ela espera uma resposta retornar antes de prosseguir.
