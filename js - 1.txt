3.

var e let são utilizados pra declarar variáveis que podem ser alteradas após a definição inicial, já const é usado para definir uma variável que, após a atribuição inicial a um valor, não pode mais ser alterado, além de que sempre precisa possuir um valor atribuído a ele, então:
const variável;
Não é permitido.
var e let também possuem uma diferença de escopo: var vaza pro escopo global quando criado dentro de um laço ou decisão, enquanto let fica dentro de onde foi declarado, seja um laço, decisão, função, etc. 
Por exemplo:
if(1 === 1) { var texto = 'ola' }; console.log(texto);
output: ola
if(1 === 1) { let texto = 'ola' }; console.log(texto);
output: erro de "texto is not defined"

No exemplo dado, não há problema nenhum em oque é feito: É criado um objeto "user" com o atributo "name" com o valor "Tiago", em seguida, o atributo tem seu valor trocado para "João", mas o valor de "user" permanece o mesmo: um objeto. Mas uma coisa que eu não lembro, é se é possível colocar mais atributos num objeto atribuido a uma constante ou não, meu instinto diz que sim mas é meio confuso o porque seria assim.

Função pode ser otimizada desta forma:

function filterUnique(numbers : number[]) { // Remove valores duplicados de um array de números.
    const uniqueNumbers = new Set([...numbers]);
    return [...uniqueNumbers];
}

Uma forma ainda mais compacta seria:

function filterUnique(numbers : number[]) { // Remove valores duplicados de um array de números.
    return Array.from(new Set(numbers));
}

E não sacrifica legibilidade.
