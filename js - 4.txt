Segundo then recebe X porque Promise.resolve("X") já é uma promise settled e todo argumento passado pro próximo .then é convertido de Promise no valor dela sem necessidade de usar await, assim o valor passado de argumento é X ao invés de Promise { X }, mas mesmo se o caso fosse diferente como por exemplo:

Promise.resolve()
    .then(() => {
        console.log("2");
        return Promise.resolve("X")
	       .then((char) => char;
    })
    .then(value => {
        console.log(value);
    });

Ainda assim o valor seria X porque novamente, a passagem de parâmetro funciona como um await esperando assim a promisse ir de pendent pra settled antes de usar.

Uma forma fácil de visualizar isso é com

const letra = Promise.resolve('X');
console.log(letra);

Aqui a promise já ta settled, mas sem await o valor de letra ainda é Promise { X }

enquanto em 

const letra = await Promise.resolve('X');
console.log(letra);

Aí sim a saída é X.
